# Pinned Supabase self-hosting baseline

| Item | Value |
|------|-------|
| Upstream repository | https://github.com/supabase/supabase (`docker/`) |
| Upstream commit | `6a421fe296346f0b85f2ff763f94b5d74f548b0c` (resolved 2026-10-29) |
| Gateway variant | Envoy v1.39.1 (upstream default `api-gw`) |
| Copied verbatim | `envoy/envoy.yaml`, `envoy/docker-entrypoint.sh`, `db/realtime.sql`, `db/jwt.sql` |
| Copied with change | `db/roles.sql` (dropped `supabase_functions_admin`: webhooks/functions are not installed) |
| Curated | `envoy/lds.template.yaml`, `envoy/cds.yaml` (generated by `envoy/curate.py` from upstream: only Auth, Realtime and server-only Storage/Broadcast routes; access log without query strings), `compose.yaml` |

Services deliberately omitted from the baseline: PostgREST/GraphQL (no browser data access to
application schemas), Edge Functions, imgproxy, Supavisor, analytics/Vector. Studio and
postgres-meta run only under the `admin` profile on a loopback port.

Images are pinned by multi-arch OCI index digest (linux/amd64 and linux/arm64). On every
baseline upgrade re-run the identity reconcile integration tests (T013): the identity
triggers are installed on the Supabase-managed `auth.users` table.
